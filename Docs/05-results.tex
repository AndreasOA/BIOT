\chapter{Results and Analysis}
\label{sec:results}

This chapter presents the experimental evaluation of the proposed \ac{xLSTM}
architectures within the \ac{BIOT} framework for multi-class EEG event
classification on the \ac{TUEV} dataset. We compare four model variants
(\ac{sLSTM}, \ac{mLSTM}, combined \ac{mLSTM}+\ac{sLSTM}, and a Linear
Transformer baseline) across three temporal window lengths (5\,s, 7\,s, 9\,s).
Each configuration is trained with five random seeds to assess stability and
statistical robustness.

%===============================================================================
\section{Model Selection Criterion}
\label{sec:model_selection_criterion}

All results reported in this chapter are derived from checkpoints selected by
\textbf{balanced accuracy on the validation set}. This design choice is
critical. The TUEV dataset is highly imbalanced (66.77\% majority class), and
minimizing cross-entropy loss often results in models that primarily favor the
majority class while suppressing minority classes without significant penalties
in loss. Balanced accuracy weights each class equally, making it substantially
more appropriate for performance assessment in this clinical classification
setting. Unless stated otherwise, all metrics, confusion matrices, and
statistical tests are based on the balanced-accuracy–selected checkpoints.

%===============================================================================
\section{Overall Performance Comparison}
\label{sec:overall_performance}

We evaluate four complementary metrics: balanced accuracy (robust to class
imbalance), Cohen’s~\(\kappa\) (agreement beyond chance), weighted F1
(performance weighted by class prevalence), and macro-\ac{AUCPR}, which is
particularly relevant for rare-event detection. Figure formats rather than
tables are used to emphasize trends, robustness, and variability.

\subsection{Overview of Aggregate Performance}

Across all configurations, performance differences between architectures are
observable but modest. \ac{xLSTM} variants generally outperform the Linear
Transformer in macro-\ac{AUCPR}, indicating improved ranking capability for rare
pathological events. However, the magnitude of these improvements is highly
dependent on the temporal window and often comparable to between-seed variance.
No model achieves a statistically significant advantage in the primary metric
(balanced accuracy) at any window length.

\subsection{Architectural Trends Across Windows}

Figure~\ref{fig:architecture_window_aucpr_macro} summarizes macro-\ac{AUCPR}
performance across models and temporal contexts.

At 5\,s windows, \ac{sLSTM} demonstrates the strongest and most stable
performance, achieving higher medians with limited overlap relative to the
Linear Transformer. This reflects improved detection quality particularly for
rare classes and is consistent with the statistically significant difference
reported in Section~\ref{sec:results_statistical_significance_summary}.

At 7\,s windows, architectural performance differences diminish. All
architectures exhibit overlapping distributions, indicating that improvements
are small relative to random-seed variability. \ac{mLSTM} exhibits competitive
central tendency but without clearly separating from the baseline.

At 9\,s windows, \ac{sLSTM} again trends higher than the Linear Transformer,
though with greater dispersion. Extended context does not uniformly benefit all
architectures; some configurations even degrade, suggesting diminishing returns
from longer temporal windows for this task.

The combined \ac{mLSTM}+\ac{sLSTM} architecture remains consistently stable
across windows but never achieves the top median value. In contrast, the Linear
Transformer displays higher variability but remains competitive.

Overall, the plot indicates that \ac{xLSTM} architectures can provide benefits
in rare-event ranking quality, particularly at shorter windows, but observed
gains are window-dependent and not uniformly robust.

\section{Computational Efficiency}
\label{sec:efficiency}

Model quality must be interpreted alongside computational cost. The mean
training time per configuration (100 epochs, identical GPU setup) is visualized
in Figure~\ref{fig:architecture_window_runtime_bar}.

The Linear Transformer is clearly the most efficient model, completing training
between 1.8–3.3 hours depending on window length, and offering a
2.3–3.4\(\times\) speed advantage over \ac{xLSTM} variants. Runtime scales
predictably and near-linearly with temporal context.

Among \ac{xLSTM} architectures, \ac{sLSTM} is the most computationally
efficient, with runtimes between approximately 4 and 7 hours. It therefore
provides the most favorable accuracy–efficiency compromise.

\ac{mLSTM} and the hybrid \ac{mLSTM}+\ac{sLSTM} models are significantly more
expensive (5.5–11 hours). Runtime scaling is superlinear with longer temporal
contexts, particularly for \ac{mLSTM}, and variability increases at 9\,s
windows, reflecting less predictable optimization behavior.

This analysis highlights that even when performance advantages exist, they must
be weighed against substantially higher computational cost, particularly for
\ac{mLSTM}-based designs.

\textbf{Implementation Note:} The observed \ac{xLSTM} runtime characteristics diverge from expectations based on the original paper~\cite{beck2024xlstm}, which emphasizes that \ac{mLSTM} is ``fully parallelizable'' and designed to scale favorably. The \texttt{xlstm} Python package used in this work may contain implementation inefficiencies that do not fully realize the theoretical parallelization potential (see \url{https://github.com/NX-AI/xlstm/issues/58}). Therefore, these runtime measurements should be interpreted as specific to the current implementation rather than as definitive architectural characteristics. Optimized implementations may yield substantially improved efficiency.

\section{Class-Specific Performance}
\label{sec:class_performance}

Aggregate metrics conceal important differences in how architectures behave
across clinically meaningful EEG event categories. Figure
\ref{fig:class_recall_vs_window_box} summarizes per-class recall as a function
of model and window length.

The dominant observation is performance stratification by class frequency. The
majority class consistently exhibits the highest recall with minimal variance.
Moderate-frequency classes maintain intermediate recall, while the rarest class
achieves consistently poor recall across all architectures and windows. This
indicates that dataset imbalance, rather than temporal modeling capability,
remains the primary limiting factor.

Architectural effects exist but are typically smaller than cross-seed
variability at 5\,s and 7\,s windows. At 9\,s windows, \ac{sLSTM} displays
improved recall in both the rarest and majority classes, although variability
remains high. Importantly, extending temporal context alone does not
systematically improve minority-class sensitivity.

To keep the main text compact, full normalized confusion matrices
(mean~\(\pm\)~std) are provided in Appendix~\ref{app:confusion_matrices}.

\section{Statistical Significance Summary}
\label{sec:results_statistical_significance_summary}

Paired statistical testing was conducted between the Linear Transformer and the
best-performing \ac{xLSTM} variant at each window (paired t-test and Wilcoxon
signed-rank test, \(n=5\), \(\alpha = 0.05\)). Full tables are provided in
Appendix~\ref{app:statistical_significance_testing}.

Only two effects reach significance in the paired t-test:
\begin{itemize}
\item \ac{sLSTM} improves macro-\ac{AUCPR} at 5\,s.
\item \ac{sLSTM} improves overall accuracy at 9\,s.
\end{itemize}

No configuration achieves statistical significance for the primary metric
(balanced accuracy). Wilcoxon tests generally do not confirm significance,
indicating these should be interpreted as indicative \emph{trends} rather than
strong evidence. Effect sizes remain modest (<5\% absolute improvement).

\subsection{Class-Specific Performance}

Per-class recall tests (Appendix~\ref{app:per_class_recall_tests}) reveal that
architectural differences are largely concentrated in specific classes rather
than uniformly distributed:

\begin{itemize}
\item \textbf{5-second windows:} No per-class recall differences reach
statistical significance. The strongest trend appears in the majority class
(Class~5), which improves for \ac{sLSTM} (\(p=0.076\), paired t-test), but
remains above the significance threshold.

\item \textbf{7-second windows:} \ac{mLSTM} shows numerical improvements in
recall for several classes, particularly Class~1, but none reach statistical
significance. Architectural effects are fully absorbed by cross-seed variance.

\item \textbf{9-second windows:} \ac{sLSTM} achieves statistically significant
improvements in per-class recall for both the rarest class (Class~0,
\(p=0.047\)) and the majority class (Class~5, \(p=0.016\)) according to the
paired t-test. However, the corresponding Wilcoxon tests do not confirm these
findings (\(p=0.125\) and \(p=0.062\), respectively), suggesting sensitivity to
individual seed behavior and warranting cautious interpretation.
\end{itemize}

Importantly, off-diagonal confusion matrix patterns show no statistically significant differences
(Appendix~\ref{app:full_cm_pattern_analysis}), indicating that architectural
choice primarily affects recognition quality within classes rather than
systematically altering misclassification patterns between classes.

\section{Summary of Key Findings}
\label{sec:key_findings}

\subsection{Performance Characteristics}

\begin{itemize}
\item \ac{sLSTM} provides the most consistent performance benefits, particularly
at 5\,s and 9\,s, although improvements are modest.
\item \ac{mLSTM} peaks at 7\,s but degrades substantially at 9\,s.
\item The combined \ac{mLSTM}+\ac{sLSTM} model is stable but never dominant.
\item The Linear Transformer remains competitive while being dramatically faster.
\end{itemize}

\subsection{Statistical Interpretation}

\begin{itemize}
\item Significant effects are rare and metric-dependent.
\item No architecture significantly outperforms the baseline in balanced accuracy.
\item Observed improvements should be treated as trends rather than definitive
evidence.
\end{itemize}

\subsection{Architectural Insights}

\begin{itemize}
\item Architectural benefits are window-dependent and sensitive to temporal context.
\item \ac{sLSTM} benefits shorter and longer sequences, whereas \ac{mLSTM}
appears tuned to intermediate context. Note that ``shorter'' and ``longer'' are
relative terms within the 5--9\,s range tested here; sequences could extend
considerably beyond this range, so these observations should not be
over-generalized as universal sequence-length characteristics.
\item Combining architectures improves stability rather than peak performance.
\end{itemize}

\subsection{Practical Implications}

\begin{itemize}
\item For deployment, \ac{sLSTM} at 5\,s provides the best balance of performance
and efficiency.
\item The Linear Transformer remains attractive for fast, predictable training.
\item Class imbalance remains the dominant challenge; architectural complexity
alone does not resolve minority-class underperformance.
\end{itemize}

Overall, \ac{xLSTM} variants offer measurable but modest benefits over the
Linear Transformer baseline. Their advantages are constrained by
window-dependence, computational overhead, and persistent dataset imbalance,
suggesting that future work should prioritize imbalance mitigation alongside
architectural refinement.
