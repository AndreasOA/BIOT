\section{Statistical Significance Testing}
\label{app:statistical_significance_testing}

This section collects all statistical tests that compare the Linear Transformer baseline against the best-performing \ac{xLSTM} variant at each window length. In the main Results chapter, we only summarize the key outcomes and point here for the full tables.

All tests are paired across random seeds ($n=5$, $\alpha=0.05$). For each comparison, we report both a paired t-test (parametric) and a Wilcoxon signed-rank test (non-parametric). Because $n=5$ is small, p-values should be interpreted carefully and together with the size of the observed differences.

\subsection{Overall Metric Comparisons}
