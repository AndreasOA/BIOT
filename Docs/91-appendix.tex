\section{Complete Confusion Matrix Collection}
\label{app:complete_confusion_matrices}

This section provides normalized confusion matrices for all architectural variants and temporal window configurations that were not included in the main results chapter. These matrices enable comprehensive analysis of class-specific performance patterns. Confusion matrices are normalized row-wise, so diagonal entries represent per-class recall (sensitivity) and off-diagonal entries show misclassification rates. All values are mean~$\pm$~standard deviation across five random seeds.

\subsection{Overview}

A confusion matrix displays the classification performance for each true class (rows) against predicted classes (columns). In this multiclass seizure classification task with six classes (0-5):
\begin{itemize}
