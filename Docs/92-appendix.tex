\section{Complete Confusion Matrix Collection}
\label{app:complete_confusion_matrices}

This section provides the full set of normalized confusion matrices referenced in the class-specific analysis in Chapter~\ref{sec:results}. Confusion matrices are normalized row-wise, so diagonal entries represent per-class recall (sensitivity) and off-diagonal entries show misclassification rates. All values are mean~$\pm$~standard deviation across five random seeds.

\subsection{Overview}

A confusion matrix displays the classification performance for each true class (rows) against predicted classes (columns). In this multiclass seizure classification task with six classes (0--5):
\begin{itemize}
\item \textbf{Diagonal values (bold):} Per-class recall---the fraction of true instances correctly classified.
\item \textbf{Off-diagonal values:} Misclassification rates---the fraction of true instances incorrectly assigned to other classes.
\item \textbf{Class distribution:} Class~0 (1.93\%), Class~1 (15.89\%), Class~2 (6.79\%), Class~3 (1.12\%), Class~4 (7.49\%), Class~5 (66.77\%).
\end{itemize}

The severe class imbalance strongly influences model behavior, with majority-class bias evident across all architectures.

\section{Statistical Significance Testing for Confusion Matrix Patterns}
\label{app:cm_statistical_tests}

This section provides statistical tests for the class-specific performance differences shown in the confusion matrices above. We first examine per-class recall (diagonal entries), then analyze whether the overall confusion pattern differs significantly between architectures.

\subsection{Per-Class Recall Comparisons}
\label{app:per_class_recall_tests}

Tables~\ref{tab:class_comparison_5s}--\ref{tab:class_comparison_9s} present paired statistical tests for per-class recall (diagonal of the normalized confusion matrix). This helps to check if improvements are concentrated in specific classes or reflect broad changes.

All tests are paired across random seeds ($n=5$, $\alpha=0.05$). For each comparison, we report both a paired t-test (parametric) and a Wilcoxon signed-rank test (non-parametric).

\subsubsection{5-Second Windows}

\begin{table}[htbp]

\subsection{Full Confusion Matrix Pattern Analysis}
\label{app:full_cm_pattern_analysis}

While the per-class recall tests above focus on diagonal entries, this subsection addresses whether off-diagonal misclassification patterns—not just diagonal recall values—differ systematically across architectures. This helps determine if architecture choice influences not only how well each class is recognized, but also how errors are distributed across the other classes.

\subsection{Methodology}

For each window length, we compare the Linear Transformer baseline against the best-performing \ac{xLSTM} variant. Each confusion matrix is a \(6 \times 6\) matrix with 36 entries (6 classes). We test the null hypothesis that the confusion matrices are equivalent using:

We perform element-wise paired t-tests for each of the 36 matrix positions across the five random seeds ($n=5$, $\alpha=0.05$). This identifies which specific confusion matrix cells differ significantly. Given the small sample size and exploratory nature of this analysis, we report uncorrected p-values and interpret findings cautiously.

\subsection{Key Findings}

\subsubsection{5-Second Windows: Linear Transformer vs. sLSTM}

No confusion matrix cell shows a statistically significant difference at $\alpha = 0.05$. The largest differences appear in:
\begin{itemize}
\item True Class~5 $\to$ Predicted Class~5 (diagonal): $p=0.076$ (also reported in Section~\ref{app:per_class_recall_tests})
\item True Class~1 $\to$ Predicted Class~5: slight reduction in misclassification for \ac{sLSTM} ($p \approx 0.15$)
\end{itemize}

The confusion patterns at 5\,s are statistically equivalent between the two architectures.

\subsubsection{7-Second Windows: Linear Transformer vs. mLSTM}

Similarly, no cell reaches statistical significance at $\alpha = 0.05$. The per-class recall improvements for \ac{mLSTM} (especially Class~1, as noted in Section~\ref{app:per_class_recall_tests}) do not translate into statistically significant changes in the full confusion matrix pattern at $n=5$.

\subsubsection{9-Second Windows: Linear Transformer vs. sLSTM}

At 9\,s, two diagonal entries were found significant in the per-class recall tests (Class~0: $p=0.047$, Class~5: $p=0.016$). These represent the strongest effects observed.

Off-diagonal changes (misclassification redistribution) do not reach statistical significance, indicating that while \ac{sLSTM} improves recall for specific classes at 9\,s, the broader confusion pattern is not fundamentally different.

\subsection{Interpretation}

The statistical tests confirm that:
\begin{itemize}
\item \textbf{Overall confusion patterns are similar} across architectures at each window length, even when individual diagonal entries (per-class recall) show numerical improvements.
\item \textbf{Small sample size ($n=5$ seeds)} limits statistical power for detecting differences in 36 matrix cells simultaneously.
\item \textbf{Observed improvements} (e.g., \ac{sLSTM} at 5\,s and 9\,s, \ac{mLSTM} at 7\,s) are concentrated in per-class recall rather than systematic changes to misclassification patterns.
\item \textbf{Class imbalance effects} persist across all architectures—majority-class bias and rare-class confusion remain consistent structural challenges regardless of architecture choice.
\end{itemize}

These findings suggest that architectural differences (Linear Transformer vs.\ \ac{xLSTM} variants) primarily influence classification thresholds and per-class sensitivity rather than fundamentally altering how errors are distributed across the confusion matrix. Future work with larger sample sizes would provide greater statistical power to detect subtle differences in confusion patterns.
